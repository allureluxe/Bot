Lancement rapide

  1. Ouvrez un terminal dans le dossier luna-web/.
  2. Lancez python3 -m http.server 8000.
  3. Ouvrez http://localhost:8000 dans votre navigateur.

Besoin d'aide détaillée ? Le fichier README.md du dossier luna-web/ explique chaque étape pour ChromeOS/Linux.
